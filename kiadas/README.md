# Kiadások

A mappa a legutóbbi kiadás lefordított, olvasható változatát tartalmazza:

- `adatbanyaszat.pdf` – nyomtatható PDF (B5),
- `adatbanyaszat.epub` – e-könyv-olvasóra.

A fájlokat a `scripts/kiadas.sh` másolja ide a GitHub Pages-en közzétett változatból, hogy a
GitHub-kiadás forráscsomagjával a Zenodo az olvasható könyvet is archiválja. A mindenkori
legfrissebb változat a webkönyvből tölthető le:
<https://complexsystemsintelligence.github.io/adatbanyaszat/>
